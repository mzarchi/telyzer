## Telegram content analysis

**_Steps:_**

1. Go to [Telegram Apps](https://my.telegram.org/auth?to=apps) to get **_api_id_** and **_api_hash_**

2. Clone repo by `git clone https://github.com/mzarchi/telyzer.git`

3. Install lib by `pip install -r requirements.txt`

4. Rename `config.py.example` to `config.py` and put your **_api_id_** and **_api_hash_** with to that

   > <sub>At this step, you must have **api_id** and **api_hash**</sub>

5. Login to your **Telegram** account by `1. Telegram Login` and save **automatically** your session in `C:\telyzer\session`

6. Use from Telyzer options
